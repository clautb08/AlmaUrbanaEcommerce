# Proyecto E-commerce - Tienda de Ropa

## Ejecutar la aplicación React

```bash
npm install
npm run dev
```

La aplicación se inicia desde `index.html` y todas las pantallas se renderizan
desde React en `src/App.jsx`.

## Descripción
Este proyecto es nuestro avance completado de un sistema E-commerce desarrollado con HTML y CSS y JS en HTML, como parte del curso de Front End en la PUCP.  
El objetivo es construir una tienda de ropa en línea que permita:

- Crear Cuenta (registro completo).
- Inicio de sesión (acceder con credenciales).
- Visualizar lista de productos con filtros por categoría:
  - Hombres
  - Mujeres
  - Niños
- Carrito de compras (con o sin productos seleccionados).
- Finalizar pedido (ingresando datos de envío y pago).
